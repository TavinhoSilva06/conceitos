Enum (enumeração) em Java é uma classe especial que representa um conjunto de constantes fixas 
e pré-definidas. É usada quando você tem um número finito de valores possíveis.             
                                                                                                                                                                                             
  Exemplo:                                                                                                                                                                                   
  public enum Dia {                                                                                                                                                                          
      SEGUNDA, TERCA, QUARTA, QUINTA, SEXTA, SABADO, DOMINGO                                                                                                                                 
  }                                                                                                                                                                                          
                                                                                                                                                                                             
  Enums podem ter campos, construtores e métodos:                                                                                                                                            
  public enum Status {                                                                                                                                                                       
      ATIVO("Ativo"),                                                                                                                                                                        
      INATIVO("Inativo");                                                                                                                                                                    
                                                                                                                                                                                             
      private String descricao;                                                                                                                                                              
                                                                                                                                                                                             
      Status(String descricao) {                                                                                                                                                             
          this.descricao = descricao;                                                                                                                                                        
      }                                                                                                                                                                                      
                                                                                                                                                                                             
      public String getDescricao() {                                                                                                                                                         
          return descricao;                                                                                                                                                                  
      }                                                                                                                                                                                      
  }
