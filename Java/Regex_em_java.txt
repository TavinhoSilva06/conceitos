 que é Regex em Java?                                                                                                                                                                     
                                                                                                                                                                                             
  Regex (Regular Expression) é um padrão de texto usado para validar, buscar, substituir ou processar strings. 
  Em Java, você usa a classe Pattern (do pacote java.util.regex) para compilar  um padrão e depois usá-lo.                                                                                                                                                                 
                                                                                                                                                                                             
  Seu regex específico:                                                                                                                                                                      
                                                                                                                                                                                             
  private static final Pattern EMAIL_PATTERN =                                                                                                                                               
          Pattern.compile("^[A-Za-z0-9+_.-]+@(.+)$");                                                                                                                                        
                                                                                                                                                                                             
  Ele valida se uma string é um email válido. Vamos quebrar cada parte:                                                                                                                      
                                                                                                                                                                                             
  ┌──────────────────┬───────────────────────────────────────────────────────────────────────────────────┐                                                                                   
  │      Padrão      │                                    Significado                                    │                                                                                   
  ├──────────────────┼───────────────────────────────────────────────────────────────────────────────────┤                                                                                   
  │ ^                │ Início da string                                                                  │                                                                                   
  ├──────────────────┼───────────────────────────────────────────────────────────────────────────────────┤                                                                                   
  │ [A-Za-z0-9+_.-]+ │ Um ou mais caracteres: letras (A-Z, a-z), números (0-9), ou símbolos (+, _, ., -) │                                                                                   
  ├──────────────────┼───────────────────────────────────────────────────────────────────────────────────┤                                                                                   
  │ @                │ O símbolo @ (literal)                                                             │                                                                                   
  ├──────────────────┼───────────────────────────────────────────────────────────────────────────────────┤                                                                                   
  │ (.+)             │ Um ou mais caracteres de qualquer tipo (o domínio)                                │                                                                                   
  ├──────────────────┼───────────────────────────────────────────────────────────────────────────────────┤                                                                                   
  │ $                │ Fim da string                                                                     │                                                                                   
  └──────────────────┴───────────────────────────────────────────────────────────────────────────────────┘

  Exemplo:                                                                                                                                                                                   
  - ✅ user@example.com — válido                                                                                                                                                             
  - ✅ john.doe+tag@dommain.co.uk — válido                                                                                                                                                    
  - ❌ @example.com — inválidoo (sem caracteres antes de @)                                                                                                                                   
  - ❌ user@ — inválido (sem domínio)                                                                                                                                                        
                                                                                                                                                                                             
  Como é usado no seu código (linha 56):                                                                                                                                                     
                                                                                                                                                                                             
  if (!EMAIL_PATTERN.matcher(request.email()).matches()) {                                                                                                                                   
      throw new ValidacaoException("E-mail inválido");                                                                                                                                       
  }                                                                                                                                                                                          
                                                                                                                                                                                             
  1. .matcher() cria um validador para a string                                                                                                                                              
  2. .matches() retorna true se a string bate com o padrão
