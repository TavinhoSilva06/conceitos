1. authentication.getPrincipal() — Obtém o "principal" (a entidade autenticada) do objeto Authentication. 
No Spring Security, o principal é o UserDetails que contém as informações do usuário logado.

2. (ClienteUserDetails) — É um cast (conversão de tipo) necessário porque getPrincipal() retorna um Object genérico. 
Aqui estamos informando ao Java: "eu sei que este object é do tipo ClienteUserDetails, converta-o para esse tipo".

3. Resultado — A variável userDetails recebe um objeto ClienteUserDetails com as informações do cliente 
autenticado, que é então usado para extrair id, nome, email e papel nos próximos passos.

Em resumo: É um padrão padrão do Spring Security para recuperar informações customizadas do usuário logado 
quando você tem um UserDetails customizado (no seu caso, ClienteUserDetails em vez do User genérico do Spring).
